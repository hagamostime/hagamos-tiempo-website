# Hagamos Tiempo

Sitio web estático e independiente de Hagamos Tiempo.

## Estructura

- `index.html`: página principal.
- `relaciones-que-nos-construyen.html`: primer artículo.
- `assets/`: fotografías utilizadas por el sitio.
- `CNAME`: dominio personalizado para el hosting.

## Flujo de actualización

1. Editar los archivos en una copia de trabajo.
2. Probar localmente la navegación, las imágenes y el formulario.
3. Publicar primero en la dirección temporal del hosting.
4. Verificar la versión móvil y de escritorio.
5. Promover la versión aprobada al dominio público.

El formulario del newsletter está integrado desde Brevo/Sibforms y requiere que ese formulario continúe activo en la cuenta correspondiente.
